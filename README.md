# Vaiinilla landing

Landing pública de Vaiinilla, construida con Astro. Presenta el recorrido del alumno y la operación de cafeterías usando capturas reales de la aplicación y los assets oficiales de marca.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run build
npm run preview
```

El panel operativo vive en `vaiinilla-web`; este repositorio es únicamente la landing pública.
